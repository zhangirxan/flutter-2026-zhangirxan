# Practice 4 — A Screen That Reacts

Экран с тремя виджетами, которые меняются: карточка-счётчик, счётчик в обе стороны и секундомер.

## Запуск
Android Studio
1. File -> Open -> папка `practice4` с `pubspec.yaml` внутри.
2. В списке устройств сверху выбрать телефон, эмулятор или Chrome.
3. Нажать Run.
