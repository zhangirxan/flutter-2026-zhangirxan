# Practice 5 — A Screen That Never Overflows

Список из двадцати контактов: аватар с бейджем непрочитанных, имя (даже очень длинное), email. Светлая и тёмная тема из одного seed-цвета.

## Запуск
Android Studio
1. File -> Open -> папка `practice5` с `pubspec.yaml` внутри.
2. В списке устройств сверху выбрать телефон, эмулятор или Chrome.
3. Нажать Run.
