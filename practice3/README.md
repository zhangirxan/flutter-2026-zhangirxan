# Practice 3 — My Profile Screen

Экран моего профиля из фото, имя, университета и фактов.

## Запуск
Android Studio
1. File -> Open -> папка `practice3` с `pubspec.yaml` внутри.
2. В списке устройств сверху выбрать телефон, эмулятор или Chrome.
3. Нажать Run.



После изменений в `assets/` или `pubspec.yaml` нужен полный перезапуск, hot reload их не подхватывает.
