# Practice 6 — Screens That Lead to Screens

Три экрана: список студентов → карточка студента → форма, которая возвращает новое имя. Именованные маршруты и диалог «Discard changes?» при выходе с несохранёнными правками.

## Запуск
Android Studio
1. File -> Open -> папка `practice6` с `pubspec.yaml` внутри.
2. В списке устройств сверху выбрать телефон, эмулятор или Chrome.
3. Нажать Run.
