# Practice 8 — A Little of Everything

Список книг — повторение недель 1–7: модель на чистом Dart, список с фильтром, своя плитка книги, экран книги, который отвечает решением, и форма добавления.

## Запуск
Android Studio
1. File -> Open -> папка `practice8` с `pubspec.yaml` внутри.
2. В списке устройств сверху выбрать телефон, эмулятор или Chrome.
3. Нажать Run.
