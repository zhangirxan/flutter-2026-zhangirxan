# Practice 7 — A Form That Validates Itself

Форма регистрации: валидатор у каждого поля, фокус и клавиатура, выбор группы и даты рождения, галочка с правилами. После регистрации — карточка с итогом, которая на ширине от 600 px становится двухколоночной.

## Запуск
Android Studio
1. File -> Open -> папка `practice7` с `pubspec.yaml` внутри.
2. В списке устройств сверху выбрать телефон, эмулятор или Chrome.
3. Нажать Run.
