# Practice 9 — Put It High, Subscribe Low

Книжный магазин: экран Books с кнопками Add и бейджем корзины, экран Cart с количеством и итогом. Сначала состояние поднято над `MaterialApp` (коммит `lifted`), потом — `Cart extends ChangeNotifier` через `provider` (`watch`, `read`, `select`, `Consumer`). Замеры и ответы — в `NOTES.md`.

## Запуск
Android Studio
1. File -> Open -> папка `practice9` с `pubspec.yaml` внутри.
2. В списке устройств сверху выбрать телефон, эмулятор или Chrome.
3. Нажать Run.
