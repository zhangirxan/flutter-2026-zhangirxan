# Practice 10 — The Data Arrives Later

Экран студентов поверх фейкового API (2 секунды, каждый третий запрос падает): вручную, через FutureBuilder, обратный отсчёт на Stream и кнопка Save, которая не теряет ошибку. Замеры — в `NOTES.md`.

## Запуск
Android Studio
1. File -> Open -> папка `practice10` с `pubspec.yaml` внутри.
2. В списке устройств сверху выбрать телефон, эмулятор или Chrome.
3. Нажать Run.
